# Настройка проекта

## Настройка переменной окружения в Windows

Для корректной работы проекта используется системная переменная окружения `VIVADO_FOLDER`.

Переменная `VIVADO_FOLDER` должна указывать на каталог, в котором расположен репозиторий `Neural_Processor`, а не на сам каталог проекта.

Например, если проект расположен по пути:

```text
D:\Projects\Vivado_Projects\Neural_Processor
```

то переменная должна иметь значение:

```text
VIVADO_FOLDER=D:\Projects\Vivado_Projects
```

# Параметры верхнего уровня

Основным модулем проекта является `top.sv`.

В верхнем уровне используются следующие параметры:

```systemverilog
module top
#(
    parameter integer FREQ       = 100_000_000,
    parameter integer BAUDRATE   = 57600,
    parameter integer RATIO      = 8,
    parameter integer PARITY_BIT = 0,
    parameter integer STOP_BIT   = 0,

    parameter string PR_DIR = "D:/Projects/Vivado_Projects"
)
```

## `FREQ`

Частота системного тактового сигнала в герцах.

Значение должно соответствовать реальной частоте сигнала, подаваемого на вход `i_clk`.

Значение по умолчанию:

```text
100_000_000 Гц = 100 МГц
```

---

## `BAUDRATE`

Скорость обмена по интерфейсу UART.

Значение должно совпадать со скоростью, установленной на стороне компьютера.

Значение по умолчанию:

```text
57600 бод
```

Поддерживаемые UART-контроллером значения:

```text
300
600
1200
1800
2400
3600
4800
7200
9600
14400
19200
28800
38400
57600
115200
230400
460800
921600
```

---

## `RATIO`

Коэффициент передискретизации UART.

Поддерживаемые значения:

```text
8
16
32
```

Значение по умолчанию:

```text
8
```

Для корректной работы должно выполняться условие:

```text
FREQ >= BAUDRATE * RATIO
```

---

## `PARITY_BIT`

Настройка бита чётности UART.

```text
0 - контроль чётности отключён
1 - нечётный паритет
2 - чётный паритет
```

Значение по умолчанию:

```text
0
```

---

## `STOP_BIT`

Количество стоповых бит UART.

```text
0 - 1 стоповый бит
1 - 2 стоповых бита
```

Значение по умолчанию:

```text
0
```

---

## `PR_DIR`

Путь к каталогу, в котором расположен репозиторий `Neural_Processor`.

Например:

```text
D:/Projects/Vivado_Projects
```

Параметр передаётся в модуль `neuron_net` и используется для загрузки параметров обученной нейронной сети из `.mem`-файлов.

Используются следующие группы файлов:

```text
Neural_Processor/files/sources/W1_*.mem
Neural_Processor/files/sources/B1_*.mem
Neural_Processor/files/sources/W2_*.mem
Neural_Processor/files/sources/B2_*.mem
```

При запуске симуляции в ModelSim параметр `PR_DIR` автоматически передаётся из переменной окружения `VIVADO_FOLDER` с помощью Tcl-скриптов.

# Запуск на ПЛИС

После генерации bitstream и программирования ПЛИС система изначально удерживается в состоянии сброса с помощью VIO.

Для запуска устройства необходимо открыть VIO в Hardware Manager и снять сигнал сброса:

```text
reset = 0
```

После снятия `reset` система начинает принимать данные по UART, выполнять классификацию изображения и передавать результат обратно по UART.
